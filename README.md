## FAQ

### What video editors does VideoPatch support?

VideoPatch supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi. New editors may be added in future updates.

### How do I extract the downloaded file?

Right-click the downloaded ZIP archive, select Extract All, and enter videopatch as the password when prompted.

### Is VideoPatch safe to use?

VideoPatch does not contain any malicious code. Some anticomponent programs may flag it as a false positive because it modifies software files.

### Can I patch multiple editors at once?

Yes, you can select and activate multiple supported video editors simultaneously from the VideoPatch interface.

### What should I do if the patch does not work?

Try running videopatch.exe as administrator. If the problem persists, reinstall your video editor and run VideoPatch again.

### Do I need to update VideoPatch after updating my video editor?

Yes, major updates to supported video editors may require a new version of VideoPatch for compatibility.

### Will patching affect my existing video projects?

No, VideoPatch only modifies the application files. All your projects, timelines, and media files remain completely unchanged.

### Which operating systems are supported?

VideoPatch currently supports Windows 10 and Windows 11. macOS and Linux versions are not available at this time.

### How do I know if the patch was successful?

Open your video editor and check if premium features like watermark-free export and advanced effects are now available.

### Can I revert the changes made by VideoPatch?

Yes, you can uninstall and reinstall your video editor to restore it to its original, unpatched state.
